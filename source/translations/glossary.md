# ALL KONJAC 三语术语表

本表用于本轮首页与四个业务页。英文为业务基准；泰语与印尼语以实际 Google 翻译初稿为基础，经语义和术语校订。品牌、联系方式及数字保持原样。

| English | 泰语 | 印尼语 | 校订原则 |
|---|---|---|---|
| konjac | บุก | konjak | 不据此推断植物物种；不自动替换为 porang。 |
| konjac ingredients | วัตถุดิบจากบุก | bahan baku konjak | 外贸原料语境，区别于日常烹饪配料。 |
| konjac powder | ผงบุก | tepung konjak | 指粉体产品，不新增纯度或认证。 |
| refined konjac powder | ผงบุกผ่านการทำให้บริสุทธิ์ | tepung konjak hasil pemurnian | “精制”指处理过程，不表示 100% 纯度，也不只表示粒度更细。 |
| konjac gum | กัมบุก | gom konjak | 食品亲水胶体；不得译为口香糖或橡胶。 |
| food grade | เกรดอาหาร | untuk pangan (food grade) | 沿用英文用途表述，不等于已取得特定认证。 |
| hydrocolloid | ไฮโดรคอลลอยด์ | hidrokoloid | 食品配方技术语境。 |
| formulation development | การพัฒนาสูตร | pengembangan formulasi | 食品配方开发。 |
| application development | การพัฒนาการประยุกต์ใช้ | pengembangan aplikasi | 指食品中的应用开发，不是软件开发、申请或求职。 |
| thickening | การเพิ่มความหนืด | pengentalan | 物性增稠，不是几何厚度。 |
| gel formation | การเกิดเจล | pembentukan gel | 不新增凝胶强度数值。 |
| texture | เนื้อสัมผัส | tekstur | 食品口感与质构，不是表面装饰。 |
| water holding | การอุ้มน้ำ | daya ikat air | 食品保水能力，不是储水容器。 |
| stability | ความคงตัว | stabilitas | 指目标性能，需按产品与工艺评估。 |
| equipment | อุปกรณ์ | peralatan | 设备，不限于单台机器。 |
| production-line integration | การบูรณาการสายการผลิต | integrasi lini produksi | 生产线系统集成。 |
| installation | การติดตั้ง | pemasangan | 现场安装，与调试分开。 |
| commissioning | การทดสอบเดินเครื่อง | komisioning | 工程调试、试运行；不是雇佣、委托或佣金。 |
| training | การฝึกอบรม | pelatihan | 操作培训，是否包含需在报价中确认。 |
| drying line | สายการอบแห้ง | lini pengeringan | 工业干燥生产线，不是几何线条。 |
| konjac dried chips | ชิ้นบุกแห้ง | irisan konjak kering | 工业加工的干片，不描述成零食薯片。 |
| dryer | เครื่องอบแห้ง | pengering | 工业干燥机，不是烘衣机。 |
| conveying | การลำเลียง | pemindahan bahan | 生产线内的物料输送。 |
| air handling | การจัดการอากาศ | pengelolaan udara | 干燥系统空气处理。 |
| slurry preparation | การเตรียมส่วนผสมเหลว | penyiapan suspensi | 混合料或浆料准备，不是婴儿粥。 |
| capacity | กำลังการผลิต | kapasitas | 设备产能，必须按项目约定。 |
| utilities | ระบบสาธารณูปโภค | utilitas | 厂房水、电等条件；不新增具体供应要求。 |
| project brief | รายละเอียดโครงการ | rincian kebutuhan proyek | 项目需求说明。 |
| specification | ข้อกำหนด | spesifikasi | 规格须依据拟供应材料或技术方案。 |
| grade | เกรด | grade | 产品等级，不解释为学校年级或单一含量指标。 |
| Home | หน้าหลัก | Beranda | 网页首页，不能直译为住宅。 |
| Breadcrumb | เส้นทางนำทาง | Jejak navigasi | 网页路径导航，不能直译为面包屑食品。 |

商务表达保留“可讨论／可能包括”“按项目确认范围”“样品需评估”等条件。没有补充物种、客户、认证、规格数字、能耗目标或性能保证。
